## 📡 Data Source

Use IPTV-org public API:

* https://iptv-org.github.io/api/channels.json
* https://iptv-org.github.io/api/streams.json

Fetch and merge channels with streams.

Each channel should include:

* id
* name
* logo
* country
* category
* stream url (m3u8)

---

## 🧠 Logic Requirements

### 1. Data Fetching

* Create a utility in `/lib/iptv.ts`
* Fetch channels and streams
* Merge them by channel id
* Return only channels with valid stream URLs

---

### 2. State Management

Use Zustand:

* store channels
* store selected channel
* store filters (search, country, category)

---

### 3. /live Page

* Display all channels in a grid
* Add search input
* Add filters:

  * country
  * category
* Clicking a channel → navigate to `/channel/[id]`

---

### 4. /channel/[id] Page

* Show:

  * video player
  * channel name
  * logo
* Load stream dynamically

---

### 5. Video Player

Use hls.js:

* If browser supports HLS → use native
* Else → use hls.js fallback
